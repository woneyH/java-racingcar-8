# java-racingcar-precourse

### 학습 목표

- 여러 역할을 수행하는 큰 함수를 단일 역할을 수행하는 작은 함수로 분리한다.
- 테스트 도구를 사용하는 방법을 배우고 프로그램이 제대로 작동하는지 테스트한다.
- 1주 차 공통 피드백(디스코드 참고)을 최대한 반영한다.  
  


---

#### 주의사항
- build.gradle 파일은 변경할 수 없으며, 제공된 라이브러리 이외의 외부 라이브러리는 사용하지 않는다.
- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현한다. 2까지만 허용한다.
- 3항 연산자를 쓰지 않는다.
- 함수(또는 메서드)가 한 가지 일만 하도록 최대한 작게 만들어라.

### 클래스 구조 계획

1. 핵심적인 객체는 자동차 클래스이다. 
2. 랜덤 난수 발생 클래스를 작성한다.
3. Input 클래스, Output 클래스를 따로 분리해서 관리한다.
4. Service 클래스에서 자동차 경주의 핵심 로직인 승패여부 판단과 난수를 이용한 
    경기진행 로직을 작성한다.
5. Controller를 통해 1~4번에서 작성한 클래스들을 통합적으로 호출하고 사용한다.


 | 클래스이름                    | 설명                          |
 |--------------------------|-----------------------------|
 | **Input class**          | 입력관련 클래스                    |
 | **Ouput class**          | 경주 결과 출력 클래스                |  
 | **Car class(Domain)**    | 자동차 클래스                     |
 | **Service class**        | 경주 핵심 로직 클래스                
 | **Controller class**     | 입력받은 값 Service 로직에 넘겨주는 클래스 |
 | **InputValid class**    | 입력받은 문자열 값 유효성 검사 클래스 |
 | **ExceptionMessage**    | 예외 메시지 enum class |


---


### 문제분석, 구현할 기능

*[ ]  입력 조건에 맞게 참가 자동차 이름을 입력받는다. 
 참가자들이 다수일 경우 ","를 기준으로 나누어 자동차(Car) 생성하는게 핵심
*[ ] 경기(난수발생)를 총 몇 번 수행할지 입력받는다.
*[ ] 1 경기마다 진행상황을 출력해준다.
*[ ] 최종적으로 우승자(공동 우승자)가 누구인지 출력형식에 맞게 출력해준다.
